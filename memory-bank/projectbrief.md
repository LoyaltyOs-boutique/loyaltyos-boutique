# Project Brief — LoyaltyOS

**Product:** LoyaltyOS — Merchant Loyalty & Client Experience Platform
**Deployment Target:** 85 Lansdowne, a multi-designer luxury fashion boutique (85B, Sarat Bose Road, Kolkata 700026)
**Status:** Approved design (2026-08-06) — implementation pending per plan

## Mission

Replace paper loyalty cards and ad-hoc WhatsApp blasts with a single dashboard where the merchant can:

1. Track every client's purchases, points and tier.
2. Store confidential styling records (measurements) and private staff notes.
3. Manage designer lookbooks (catalogue) and import from Instagram / CSV / PDF.
4. Compose and send segmented WhatsApp marketing campaigns.
5. Run the in-store POS counter (billing) with automatic points accrual and redemption.
6. View business insights (campaign CTR, testimonials, loyalty-vs-walk-in revenue).
7. Give each client a private web portal to see points, lookbooks, measurements and earn review rewards.

**Business Goal:** Increase repeat purchase rate (68% → 75%) and loyalty revenue share (72% → 80%).
